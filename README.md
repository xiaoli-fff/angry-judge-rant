A short rant about a printer that only runs out of ink at 11:58 p.m. on deadline night — then jams, mocks me with a flawless test page, and ends up sleeping in the hallway, unplugged, thinking about what it did.

## Run it

```sh
node main.ts
```

The program writes the one line to the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`) as `entry.txt`.
